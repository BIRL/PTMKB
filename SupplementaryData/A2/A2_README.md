# Prerequisites

To launch this script, ensure the following:

1. Make sure you have processed dbPTM data (see Supplementary Data A1 for more info)

2. A Python virtual environment with the libraries installed. The libraries are provided in the `A2_Requirements.txt` file.

# How to run
To launch the script, simply call the command:
```bash
python A2_Case_Study_Script.py
```

A list of figures will be generated inside a folder

# References
The list of proteins that were used for this case study can be seen in the `A2_Proteins.md` file. The file includes the protein, its accession number, the representative sites used for phosphorylation, and their references in PubMed IDs.
